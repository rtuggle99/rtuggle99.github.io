One string per line; ε is the empty string.

A PDA can have several moves available at once, and it follows all of them. The computation tree shows every branch, one move per level. Each box is a configuration: the state, the stack beside it (top first), and underneath, the input not yet read. The PDA accepts if some branch reads all of the input and is then in an accept state, whatever is left on the stack (✓, and that branch turns green). A branch with no move left dies (×), and a branch that comes back to a configuration it was already in (↻) is only going in circles, so it isn't followed further.

A PDA's tree can be infinite (for example, ε-moves that keep pushing), so the drawing stops at a size limit (…). The Accepted/Rejected verdict, the tests and the language listing never depend on that limit: they use an exact algorithm based on the PDA's equivalent context-free grammar.
