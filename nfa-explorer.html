One string per line; ε is the empty string.

An NFA can have several moves available at once: several arrows for the same symbol, or ε-arrows it may take without reading anything. It follows all of them at once, and the computation tree shows every branch, one move per level. Each box is a state, with the input not yet read underneath. The NFA accepts if some branch reads all of the input and ends in an accept state (✓, and that branch turns green); a branch with no move left dies (×), and a branch that comes back to a configuration it was already in (↻) is only going in circles, so it isn't followed further.
