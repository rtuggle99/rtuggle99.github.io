Pattern Explorer

Play with patterns written in the notation of Kozen's Automata and Computability.

Note: parentheses are sometimes allowed to be members of Σ, but this website doesn't allow that.

  • ( ) — grouping

The following symbols can't be in Σ, since Kozen's definition reserves them as pattern syntax.

Atomic
  • ∅ — empty pattern
  • ε — empty string
  • # — any character
  • @ — any string
Compound
  • ∪ — union
  • ∩ — intersection
  • ∘ — concatenation
  • ~ — complement
  • * — Kleene star

Anything else you type is treated as a character of the alphabet. Concatenation is written by simply placing expressions next to each other (no symbol needed), or you can write the explicit ∘ symbol if you prefer; both mean the same thing.
