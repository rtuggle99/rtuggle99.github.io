2D Triangulation Practice

Six interactive exercises, best done in order, followed by a visualization tool.

  1. Validate the TriangulationPractice recognizing valid and invalid triangulations of a 2D point set.
  2. Validate the Partial TriangulationPractice recognizing valid and invalid partial triangulations of a 2D point set.
  3. Classify the TrianglesPractice classifying triangles by how many boundary edges they have.
  4. Select the Removable TrianglesPractice recognizing which triangles can be taken out and still leave a valid partial triangulation.
  5. Climb to the RootPractice finding the parent of a node.
  6. Order the ChildrenPractice finding the children of a node in order.
  7. Visualize the ForestPlace your own points, then see the whole reverse-search forest they produce.
