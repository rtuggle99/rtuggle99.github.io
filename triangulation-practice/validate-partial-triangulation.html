Validate the Partial Triangulation

Practice recognizing valid and invalid partial triangulations of a 2D point set.

A partial triangulation of a 2D point set has triangles meeting only at shared edges or vertices, and boundary edges (edges belonging to only one triangle) that join end to end into a single loop, with each boundary point belonging to exactly two boundary edges.
