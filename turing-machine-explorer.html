Turing Machine Explorer

Draw a deterministic Turing machine and lock it in, then give it inputs and watch it accept, reject, or run forever. Any arrow you leave out goes to qrej.

One string per line; ε is the empty string.

The tape is infinite to the right only. The input starts at the left end with the head on its first symbol, and ⊔ is the blank. Moving left from the first cell leaves the head where it is. The machine halts as soon as it enters qacc or qrej.

A string gets labeled “Loops forever” when the machine runs on it and reaches the same configuration twice, which proves the machine never halts on that string. A machine can also run forever on a string without repeating, and no program can always detect that (the halting problem), so after 20,000 steps you get “No verdict” instead.
